Lesson 13 · Measurement error and misclassification

Part III · Causal inference, measurement and disease burden

Classical and Berkson exposure error, regression dilution, validation studies and regression calibration, SIMEX, and misclassification of binary variables.

About 3 hours Before this: Lessons 8 and 12 Threads: bias · uncertainty · frequentist ↔︎ Bayesian

By the end of this lesson you will be able to

  • distinguish classical from Berkson error, and predict the bias each causes;
  • explain regression dilution and calculate the attenuation factor;
  • use a validation subsample to correct an estimate by regression calibration;
  • explain how SIMEX corrects for error by adding more of it;
  • predict the effect of non-differential and differential misclassification, and correct for it with assumed sensitivity and specificity.

Why it matters. No air pollution study measures each child’s true exposure. Land-use regression models, monitors and questionnaires all err. In our cohort, the true effect of NO₂ is an odds ratio of 1.15 per 10 µg/m³, but the fully adjusted estimate using modeled NO₂ is only about 1.05. Measurement error, not confounding, causes most of that gap. Knowing which kind of error you have tells you whether, and how, to correct.

13.1 Classical and Berkson error

Classical error adds noise to the true value: a noisy monitor, a crude exposure model. It flattens exposure–response slopes toward zero, which is called regression dilution. Berkson error goes the other way: everyone is assigned a group value, such as their district’s average, and the true values scatter around it. It barely biases a linear slope, but it widens the confidence interval. Change the error type and size, and compare the estimate with the truth.

AStandard notation

\[\text{classical: } W = X + U, \quad U \perp X\] \[\text{Berkson: } X = W + U, \quad U \perp W\] \[\hat\beta_W \approx \lambda\,\beta, \qquad \lambda = \frac{\sigma^2_{X \mid Z}}{\sigma^2_{X \mid Z} + \sigma^2_U}\]

\(X\) = true exposure, \(W\) = measured, \(Z\) = covariates; \(\lambda\) is the reliability ratio (attenuation factor).

BModel list and R

# classical error attenuates
glm(asthma ~ I(no2_modeled / 10) + ses + green,
    family = binomial, data = cohort)
# true exposure (simulation only)
glm(asthma ~ I(no2_true / 10) + ses + green,
    family = binomial, data = cohort)

CHow it’s reported

Further reading: Carroll et al. (2006) is the standard text; Armstrong (1998) explains classical and Berkson error for environmental exposures; Zeger et al. (2000) apply these ideas to air pollution studies.

13.2 Validation data and regression calibration

To correct for classical error you need to know how big it is. A validation study measures the exposure better in a subsample: here, 280 children wore personal NO₂ monitors. Regression calibration uses the validation data to predict each child’s true exposure from the error-prone one, then fits the outcome model with the predicted exposure. Its key ingredient is the calibration slope, which is usually below 1.

AStandard notation

\[E[X \mid W, Z] = \alpha_0 + \alpha_1 W + \alpha_2^\top Z \quad \text{(validation data)}\] \[\mathrm{logit}\,P(Y = 1) = \beta_0 + \beta\,\widehat{E}[X \mid W, Z] + \gamma^\top Z\]

BModel list and R

val <- cohort |> filter(validation)
cal <- lm(no2_personal ~ no2_modeled + ses + green,
          data = val)
cohort$no2_cal <- predict(cal, newdata = cohort)
glm(asthma ~ I(no2_cal / 10) + ses + green,
    family = binomial, data = cohort)

CHow it’s reported

NoteR code (optional): regression calibration with a bootstrap interval 
rc_or <- function(d) {
  cal <- lm(no2_personal ~ no2_modeled + ses + green, data = filter(d, validation))
  d$no2_cal <- predict(cal, newdata = d)
  exp(coef(glm(asthma ~ I(no2_cal / 10) + ses + green, family = binomial, data = d))[2])
}
naive <- exp(coef(glm(asthma ~ I(no2_modeled / 10) + ses + green, family = binomial, data = cohort))[2])
c(naive = unname(naive), calibrated = unname(rc_or(cohort)))
#>      naive calibrated 
#>   1.049147   1.088262
set.seed(13)
boot <- map_dbl(1:200, \(b) rc_or(slice_sample(cohort, prop = 1, replace = TRUE)))
quantile(boot, c(0.025, 0.975))
#>      2.5%     97.5% 
#> 0.9029321 1.3283195

Further reading: Rosner et al. (1990) developed regression calibration for logistic regression; Keogh et al. (2020) give practical guidance on validation studies and simple corrections; Shaw et al. (2020) cover more complex methods.

13.3 SIMEX: correcting by adding more error

If the error variance is known, simulation extrapolation (SIMEX) estimates what the result would be with no error by first making the error worse. Add extra noise of increasing size, refit, and watch the estimate fall. Then extrapolate the trend back to the point where the total error would be zero.

Further reading: Cook and Stefanski (1994) introduced SIMEX; Carroll et al. (2006) explain its extrapolation step; Shaw et al. (2020) compare SIMEX with other corrections.

13.4 Misclassification of binary variables

For binary variables, measurement error is misclassification, described by sensitivity and specificity. Suppose the analysis used the wheeze questionnaire instead of a clinical diagnosis of asthma. If the questionnaire errs equally in high- and low-NO₂ children (non-differential), the odds ratio is usually biased toward 1. If parents of highly exposed children report wheeze more readily (differential), the bias can go either way. Knowing or assuming sensitivity and specificity, you can correct the counts.

AStandard notation

\[E[a^*] = Se\cdot a + (1 - Sp)(n - a)\] \[\hat a = \frac{a^* - (1 - Sp)\, n}{Se + Sp - 1}\]

\(a^*\) = observed positives in a group of size \(n\); \(\hat a\) = corrected number of true cases.

BModel list and R

correct <- function(pos, n, se, sp)
  (pos - (1 - sp) * n) / (se + sp - 1)
# or a probabilistic bias analysis:
# episensr::probsens(...)

CHow it’s reported

WarningCommon pitfall

Assuming that non-differential error always biases toward the null, so a non-null result must be “conservative”. That holds only on average and for binary exposures with independent errors. For exposures with three or more categories, for errors that are correlated with errors in confounders, or in any single study by chance, the estimate can be pushed away from the null.

TipBayesian preview

A Bayesian measurement-error model treats each child’s true exposure as an unknown parameter, informed by the modeled value, the validation data and its relation to the outcome, all at once. Uncertainty about the error is carried into the final interval automatically. Lesson 24 builds this as a hierarchical model.

Further reading: Jurek et al. (2005) on why non-differential misclassification need not bias a single study toward the null; Fox et al. (2021) on simple and probabilistic bias analysis for misclassification; Keogh et al. (2020) on misclassification in observational epidemiology.

Key takeaways

  • Classical error (noise added to the truth) attenuates slopes toward zero; Berkson error (truth scattered around an assigned value) mostly costs precision.
  • The attenuation factor is the share of exposure variance, after accounting for covariates, that is true signal.
  • Validation data make correction possible: regression calibration replaces the measured exposure by its expected true value.
  • SIMEX adds error deliberately and extrapolates back to zero error.
  • Non-differential misclassification usually, not always, biases toward the null; differential misclassification can bias in either direction.
