Lesson 22 · Bayesian regression and GLMs

Part V · Bayesian modeling

Bayesian logistic regression, priors for regression coefficients, answering questions with posterior draws, posterior predictive checks, and reporting a Bayesian analysis.

About 3 hours Before this: Lessons 8, 12 and 19–21 Threads: likelihood · uncertainty · frequentist ↔︎ Bayesian

By the end of this lesson you will be able to

  • fit a Bayesian logistic regression and compare it with the frequentist fit;
  • choose weakly informative priors for regression coefficients on the odds ratio scale;
  • answer substantive questions, including causal contrasts, by computing on posterior draws;
  • check a model’s fit with posterior predictive checks, and recognize overdispersion;
  • report a Bayesian analysis completely.

Why it matters. This is where Lessons 8 and 19–21 meet. The models are the same GLMs; the Bayesian version adds priors and returns draws. The draws make two things easy that are awkward otherwise: probability statements about effects (“how likely is it that the OR exceeds 1.1?”), and uncertainty for derived quantities such as the cases prevented by an intervention (Lesson 12).

22.1 Bayesian logistic regression

The NO₂–asthma model of Lesson 8, with priors. Each 10 µg/m³ gets a prior on its log odds ratio; the adjustment variables get weakly informative priors too. With the full cohort, the prior barely matters. With a small sample, it does. Move the sample size and the prior, and compare the posterior with the frequentist estimate.

priorfrequentist estimate and 95% CIposterior

AStandard notation

\[Y_i \sim \mathrm{Bernoulli}(\pi_i), \qquad \mathrm{logit}\,\pi_i = \alpha + \beta\,\frac{\mathrm{NO}_{2,i}}{10} + \gamma^\top z_i\] \[\beta \sim \mathrm{Normal}(0, 0.5^2), \quad \gamma_k \sim \mathrm{Normal}(0, 1), \quad \alpha \sim \mathrm{Normal}(-1.8, 1.5^2)\]

A Normal(0, 0.5²) prior on the log OR gives 95% prior probability to ORs between 0.38 and 2.7 per 10 µg/m³.

BModel list and R

fit <- brms::brm(
  asthma ~ I(no2_modeled / 10) + ses + green +
    parent_smoke + sex,
  family = bernoulli, data = cohort,
  prior = c(prior(normal(0, 0.5), class = b,
                  coef = "Ino2_modeledD10"),
            prior(normal(0, 1), class = b),
            prior(normal(-1.8, 1.5),
                  class = Intercept)))

CHow it’s reported

NoteR code (optional): the same posterior by normal approximation, in base R 
X <- model.matrix(~ I(no2_modeled / 10) + ses + green + parent_smoke + sex, data = cohort)
y <- cohort$asthma
prior_sd <- c(1.5, 0.5, rep(1, ncol(X) - 2)); prior_mean <- c(-1.8, rep(0, ncol(X) - 1))

neg_log_post <- function(b) {
  eta <- X %*% b
  -sum(y * eta - log1p(exp(eta))) + sum((b - prior_mean)^2 / (2 * prior_sd^2))
}
opt <- optim(rep(0, ncol(X)), neg_log_post, method = "BFGS", hessian = TRUE)
post_sd <- sqrt(diag(solve(opt$hessian)))
exp(opt$par[2] + c(median = 0, low = -1.96, high = 1.96) * post_sd[2])   # OR per 10 ug/m3
#>    median       low      high 
#> 1.0533092 0.9474967 1.1709386
NoteR code (optional, not run when the site builds): the full brms model 
fit <- brms::brm(
  asthma ~ I(no2_modeled / 10) + ses + green + parent_smoke + sex,
  family = bernoulli, data = cohort, chains = 4, cores = 4, seed = 22,
  prior = c(brms::prior(normal(0, 0.5), class = b, coef = "Ino2_modeledD10"),
            brms::prior(normal(0, 1), class = b),
            brms::prior(normal(-1.8, 1.5), class = Intercept)))
summary(fit)
draws <- posterior::as_draws_df(fit)
mean(exp(draws$b_Ino2_modeledD10) > 1)

Further reading: Gelman et al. (2008) propose weakly informative priors for logistic regression; Greenland (2007) on Bayesian regression in epidemiology; Bürkner (2017) describes brms.

22.2 Answering questions with posterior draws

Once you have posterior draws, every question is a computation on them. What is the probability that the odds ratio exceeds 1? That it exceeds 1.1? And, combining with Lesson 12, how many asthma cases per 1,000 children would a 10 µg/m³ reduction prevent? For that, g-computation is run once for every draw, giving a full posterior for the causal quantity.

AStandard notation

\[P(OR > c \mid y) \approx \frac{1}{S}\sum_s 1\{e^{10\beta^{(s)}} > c\}\] \[\Delta^{(s)} = \frac{1}{n}\sum_i\Big[\pi_i^{(s)}(x_i) - \pi_i^{(s)}(x_i - 10)\Big]\]

BModel list and R

draws <- posterior::as_draws_df(fit)
mean(exp(draws$b_Ino2_modeledD10) > 1.1)
# g-computation on every draw
p_obs <- brms::posterior_epred(fit)
p_int <- brms::posterior_epred(fit,
  newdata = mutate(cohort, no2_modeled = no2_modeled - 10))
cases_prevented <- 1000 * rowMeans(p_obs - p_int)
quantile(cases_prevented, c(.025, .5, .975))

CHow it’s reported

Further reading: Gelman, Hill, et al. (2020) on computing with posterior simulations; Kruschke (2015) on posterior probabilities of meaningful effects; Hernán and Robins (2020) on combining outcome models with standardization.

22.3 Posterior predictive checks

Does the model reproduce the data? A posterior predictive check simulates new datasets from the fitted model, one per posterior draw, and compares them with the real data. Here the data are daily visits by Old Town residents aged 65+. A Poisson model with only an intercept, a Poisson model with season and day of week, and a negative binomial model are checked against the observed distribution and its variance.

observed20 replicated datasets

AStandard notation

\[y^{\text{rep}(s)} \sim p(y \mid \theta^{(s)}), \qquad p_B = P\big(T(y^{\text{rep}}) \ge T(y) \mid y\big)\]

\(T\) = a test statistic, here the variance-to-mean ratio. \(p_B\) near 0 or 1 signals misfit.

BModel list and R

brms::pp_check(fit, ndraws = 20)
brms::pp_check(fit, type = "stat",
               stat = \(y) var(y) / mean(y))
# switch the likelihood:
brms::brm(..., family = negbinomial)
TipBayesian preview

Posterior predictive checks ask whether the model could have produced the data. They don’t choose between models. For that, Lesson 23 compares models by their out-of-sample predictive accuracy (LOO) and by Bayes factors, and shows when those two disagree.

Further reading: Gabry et al. (2019) on posterior predictive checks; Gelman et al. (2013) on model checking with replicated data; Ver Hoef and Boveng (2007) on choosing between quasi-Poisson and negative binomial models.

22.4 Reporting a Bayesian analysis

A Bayesian result is only interpretable alongside the choices that produced it. Reporting guidelines ask for the following, which together let a reader judge and reproduce the analysis:

  • the model, written out, and the reason for each prior, with a prior predictive check where helpful;
  • the software, sampler settings (chains, iterations, warm-up) and convergence diagnostics (R-hat, effective sample sizes, any divergences);
  • posterior summaries: medians and credible intervals, and posterior probabilities for the questions of interest;
  • posterior predictive checks of fit;
  • a sensitivity analysis under alternative reasonable priors;
  • the data and code.

CHow it’s reported

Further reading: Kruschke (2021) set out the Bayesian analysis reporting guidelines; Gelman, Vehtari, et al. (2020) describe the full Bayesian workflow; Spiegelhalter et al. (2004) on reporting Bayesian analyses in health research.

Key takeaways

  • Bayesian GLMs use the same model equations as Lesson 8, plus priors on the coefficients.
  • Priors on log odds ratios are easiest to set by thinking about plausible odds ratios; weakly informative priors rule out absurd values.
  • With much data the posterior matches the frequentist fit; with little data the prior matters, and its choice must be justified.
  • Posterior draws answer any question, including probabilities of meaningful effects and causal contrasts by g-computation.
  • Posterior predictive checks reveal misfit such as overdispersion; switch the likelihood when they fail.
